# 经营罗盘 v1.0.39

本版把团队账号、经营筛选、费率视觉口径和 QwenPaw 工具链一起收稳。老板查看费率时使用统一阈值，运营筛选品类和型号时减少来回操作，QwenPaw 则可以基于明确的数据范围和公式完成运营分析与 AI 创作。

## 费率统一判定

- `≤9.5%` 显示绿色，表示达到合格线。
- `>9.5% 且 ≤11%` 显示黄色，表示需要关注。
- `>11%` 显示红色，表示超过预警线。
- 整店、类目、商品、TOP 图、经营矩阵、推广类型和计划详情全部使用同一套颜色规则。
- 公式不因颜色变化：整体费率使用推广花费除以净 GSV，计划费率使用计划花费除以计划推广成交金额；无有效分母时显示 `--`。

## 品类与商品筛选

- 筛选工具移动到汇总和 TOP 图下方、经营明细表上方，查看结果与调整条件处于同一工作区。
- 品类与型号双向联动，并支持搜索、全选、清空和一键清除全部筛选。
- 品类 360 与商品排行分别支持最多 3 组手动保存的筛选组合，可快速应用、单独删除或清空历史。
- 点击筛选区域外部会自动收起；移动端筛选面板使用可视窗口安全高度，不再被矩阵或页面边缘裁切。
- 自定义日期与上传日期自动保持先后顺序，直接选择结束日期即可快速查看单日。

## 团队账号与成员名额

- 新用户使用“用户名 + 密码 + 团队邀请码”注册，不需要邮箱验证码。
- 旧 QQ 邮箱账号继续兼容登录，不影响已有成员。
- 用户可修改显示名称，登录用户名保持不变。
- 平台超级管理员不占团队名额、不显示在团队成员列表中，也不能被误加入普通团队成员关系。

## QwenPaw 精准运营分析

- 可按店铺、日期范围、报表周期、实体类型、实体 ID 和指标列表读取经营数据。
- 返回标准指标、公式、数据覆盖情况和未匹配实体，方便核对分析范围。
- AI 创作流程支持参考图登记、需求解析、三套提示方案、创建任务、重试、取消、Photoshop 打开与修改回传。
- 关键工具调用写入审计记录，没有真实工具回执时不会声称操作已经完成。

## 团队网页版源码

`cloud-data-hub` 继续随主仓库完整开源，包含账号登录、团队与店铺权限、邀请码、设备授权、报表上传、商品资料、整店总览、品类 360、商品排行和数据仓库，可使用 Docker Compose 或 Node.js + systemd 独立部署。

## 价格数据边界

本版没有改动淘宝/天猫价格采集链路。价格仍只从用户授权浏览器中观察，敏感内容脱敏后原子写入本地文件，再从该文件读回并解析。后端不会直接请求淘宝或天猫商品、价格、优惠或评价接口；证据不能精确闭合到分时保持不可用。
