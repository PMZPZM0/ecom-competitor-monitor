# 经营罗盘 v1.0.35

这是“天猫竞品监控”正式升级为“经营罗盘”的首个版本。本次不只是改名，还新增了可独立部署的团队网页版、桌面与云端报表同步、完整运营数据库和统一指标计算核心。

## 品牌与安装

- 桌面窗口、系统托盘、安装器、开始菜单、开发源码快捷方式、使用说明和团队网页版统一使用“经营罗盘”。
- Windows 安装包修复共享运营核心漏打包、托盘图标路径和后台初始化阻塞，启动时先显示界面，再恢复历史队列。
- 开发源码快捷方式继续启动 `D:\电商监控` 当前源码，修复 Windows PowerShell 5 对无 BOM 中文脚本的解析失败。
- 保留 `ecom-monitor://` 团队绑定协议与旧版本更新兼容性，不把账号、Cookie 或本机密钥写入安装包。

## 运营数据工作台

- 整店总览、品类 360、商品排行和数据仓库改为四个独立的一屏工作区，统一顶部导航、店铺与日期筛选。
- 日期支持今天、昨天、上周、本月、上月和自定义范围；报表上传可选择日/周/月/自定义周期，自动识别统计日期后仍可人工修正。
- 数据仓库按统计日期折叠，一次只展开一个日期；支持整组选择、展开后选择单份报表、批量删除和清空。
- 支持商品排行、品类 360、单品付费、品类付费等报表识别，提供预览、店铺归属、文件名维护和来源去重。
- 商品资料按“店铺 + 商品 ID”维护型号与品类，支持模板下载、表格导入、手工新增、重复拦截、筛选和导出。
- 增加自定义销售扣除，录入大单扣除后同步修正整店、品类和单品净销售与相关比率。
- 店铺可以删除但历史报表保留为“未归属店铺”，避免误删业务数据。
- AI 分析增加清空能力；上传、保存、删除和同步操作提供明确的进行中、成功或失败反馈。

## 指标与推广口径

- 净 GSV 统一为“支付金额 - 成功退款金额”，店铺、品类、单品和趋势使用同一底层汇总结果。
- 推广类型整体费率统一为“推广类型总花费 ÷ 关联商品链接净 GSV”。
- 展开后的计划费率统一为“计划花费 ÷ 计划推广成交金额”；计划成交不会错误复用整条商品链接的总成交。
- 全站推广通常按一个计划展示；关键词、人群等可展示多个计划。外层看推广类型整体，内层看每个计划的花费、推广成交、ROI 和计划费率。
- 品类 360 与商品排行共享同一映射和公式，推广类型与计划数量、颜色和明细保持一致；未知的新推广类型自动独立汇总。
- 桌面端与团队网页版加载字节一致的 `operationsCore.js`，避免新建团队或重新上传后出现口径漂移。

## 团队网页版开源

- 新增 `cloud-data-hub/` 完整源码，可使用 Docker Compose 或 Node.js + systemd 独立部署，并提供 Caddy 反向代理和环境变量示例。
- 使用 QQ 邮箱 + 团队邀请码免验证码注册；账号密码登录后可在已加入团队间切换，也可主动退出或由管理员移除。
- 一个店铺对应一个独立团队；管理员按成员逐个勾选可查看店铺，成员不会默认看到所有店铺。
- 团队管理员可维护成员备注、团队管理员、人数上限、邀请码容量、设备上限、设备授权与店铺权限。
- 超级管理员可开关普通用户自助创建团队，创建、编辑、封禁、恢复、解散或永久删除团队，并调整成员与默认 2 GB 云空间额度。
- 上传者只能删除自己上传的报表；团队管理员和平台管理员按权限管理团队数据，所有关键操作写入审计记录。
- 网页端提供整店总览、品类 360、商品排行、数据仓库、商品资料和销售扣除，计算逻辑与桌面端一致。

## 桌面与云端联动

- 团队管理员可生成同步授权码，限制可同步店铺和设备数量，并随时撤销设备。
- 桌面端在“运营数据 > 数据仓库 > 云端团队数据”绑定服务器，点击“立即同步”读取最新团队报表。
- 同步为只读的“团队云端报表 → 本机工作台”；本机上传的数据继续保留，按云端来源和报表身份去重。
- 淘宝登录、Cookie、浏览器资料、价格抓取证据、飞书凭证、模型 Key、QwenPaw 运行时和聊天记录不会上传云端。

## 商品抓取与交互修复

- 多 SKU 部分缺货不再误报整个账号掉线；有货 SKU 保留独立抓取结果，证据不足时保持未验证。
- 优化型号回填、SKU 捕获等待和百亿补贴等价格渠道的独立证据处理，不以历史价格或其他 SKU 猜测当前值。
- 主 SKU 最多设置 3 个并列展示；未设置时自动选择最低已验证 SKU，监控卡不会被无关批量任务带入加载状态。
- 优化删除、主 SKU 保存、数据仓库日期展开、品类 360 和商品排行计划展开的响应速度。
- 开发源码版和安装版均使用当前“经营罗盘”标题，应用后台启动、窗口恢复和托盘切换保持一致。

## 开源与验证

- 桌面端和团队网页版均包含源码、依赖锁文件、部署示例和自动化测试；运行数据、`.env`、授权码密钥和上传报表被排除在仓库之外。
- 发布前完整测试：609 项通过，覆盖浏览器本地证据落盘边界、账号与价格渠道隔离、运营公式、云同步、团队权限、报表导入和桌面打包。
- Windows 安装包已在本机完成启动与健康检查；GitHub Actions 会分别生成 Windows、Intel Mac 和 Apple Silicon Mac 构建。

- Intel Mac：`经营罗盘-1.0.35-mac-x64.dmg`
- Apple Silicon Mac：`经营罗盘-1.0.35-mac-arm64.dmg`
