# v1.0.39

## 费率口径与经营展示

- 桌面端和团队网页版统一使用 `≤9.5%` 绿色、`>9.5% 且 ≤11%` 黄色、`>11%` 红色的费率状态。
- 整店指标卡、类目销售贡献、类目/商品 TOP 图、经营矩阵、推广类型与推广计划详情全部复用同一判定函数，不再出现同一费率在不同位置颜色不一致。
- 费率计算口径保持不变：整店、品类、商品和推广类型整体费率为推广花费除以对应净 GSV；展开后的计划费率为计划花费除以计划推广成交金额。缺少有效分母时显示 `--`。

## 筛选与日期交互

- 品类 360 与商品排行的筛选工具统一放在汇总和 TOP 图下方、经营明细表上方，减少跨区域操作。
- 品类和型号继续双向联动；支持搜索、全选、清空、最多 3 组手动保存的品类组合、单组删除和清空历史。
- 网页筛选浮层扩大可用高度，移动端使用安全区内的全宽面板；点击组件外部会自动收起，本地开发版的原生筛选也同步补齐外部点击收纳。
- 自定义日期和上传日期始终保证开始日期不晚于结束日期。用户直接修改结束日期查看某一天时，开始日期会自动跟随，不再要求重复选择。

## 团队账号

- 新注册改为“用户名 + 密码 + 团队邀请码”，不再要求 QQ 邮箱；旧 QQ 邮箱形态账号继续兼容登录。
- 用户可在个人资料中修改显示名称，登录用户名保持稳定；成员列表优先显示个人名称。
- 平台超级管理员不加入普通团队成员关系、不占团队人数上限，也不会显示在团队成员列表中；旧数据中的超级管理员成员关系会在读取时忽略。

## QwenPaw 运营与创作工具

- 新增可审计的运营数据查询服务，支持店铺、起止日期、日/周/月/自定义周期、店铺/品类/商品/人群实体、实体 ID 与指标列表精准过滤。
- 新增运营指标与公式说明工具，返回净 GSV、退款、推广花费、推广成交、费率、经营 ROI、平台 ROI、访客、转化、点击等标准字段，并明确数据覆盖与未匹配实体。
- AI 创作工具补齐参考图登记、创作需求解析、商业/保守/创意三套提示方案、生成任务重试与取消，以及 Photoshop 打开和修改后同步回传。
- QwenPaw 系统说明要求先取得真实工具回执再声称完成，避免把建议或文本模拟成已经执行的操作。

## 开源与分发

- 桌面应用与团队网页版统一为 `1.0.39`；`cloud-data-hub` 账号、团队、权限、报表、运营工作台和部署源码继续完整开源。
- GitHub Actions 对 Windows x64、macOS Intel 与 macOS Apple Silicon 分别执行依赖安装、测试、静态检查和打包，全部成功后创建正式 Release。
- 淘宝/天猫价格抓取边界没有变化：仅使用授权浏览器观察结果，脱敏后原子写入本地文件，再从文件读回解析；后端不直连商品、价格、优惠或评价接口。

# v1.0.38

## 矩阵行级环比

- 品类 360 与商品排行移除重复的大指标卡，环比直接显示在每条经营矩阵记录中。
- 固定字段覆盖支付金额、成功退款、净 GSV、推广花费、推广成交、ROI 和推广费率；所有结果继续使用当前店铺、当前实体和当前统计周期的同口径数据。
- 品类与商品分别保存环比开关。上涨为红色、下降为绿色、无有效同期数据为灰色 `--`，不会补零或借用其他店铺、其他实体的数据。

## 自定义数据与排序

- 品类和商品矩阵均可从标准化经营与付费字段中追加最多 8 个数据列。
- 自定义列可点击表头参与排序，并支持拖动排序、上移、下移；两类矩阵各自保存列选择和顺序，刷新后仍然保留。
- 设置面板达到上限后会禁用未选字段，并持续显示已选数量，避免无反馈的超量操作。

## 性能与移动端

- 筛选结果、矩阵汇总、同期实体索引和行组件使用缓存，切换排序、环比和自定义列时减少重复扫描与整表重绘。
- 手机窄屏将固定字段和自定义字段重排为卡片内容，表格滚动限制在矩阵内部，不推动整页横向溢出。
- 桌面开发版和团队网页版使用相同的计算行为、字段上限、排序规则及环比颜色。

## 开源与分发

- `cloud-data-hub` 团队网页版源码继续完整开源，包含账号、团队、权限、报表、商品资料、设备同步及 Docker/systemd 部署配置。
- 桌面应用与团队网页版版本统一为 `1.0.38`；GitHub Actions 构建 Windows x64、macOS Intel 和 macOS Apple Silicon 安装包并创建正式 Release。
- 淘宝/天猫价格抓取边界没有变化：仅使用授权浏览器观察结果，脱敏后原子写入本地文件，再从文件读回解析；后端不直连商品、价格、优惠或评价接口。

# v1.0.37

## 自动环比与自定义指标

- 桌面端和团队网页版的整店、品类、商品指标卡自动跟随当前日期范围选择日环比、周环比、月环比、近 7 天、近 15 天或等长区间环比，不再逐卡勾选。
- 今天/昨天对比前一日；本周/上周对比上一自然周相同进度；本月/上月对比上月相同进度；连续区间对比紧邻的等长前一周期。
- 上涨使用红色，下降使用绿色，持平使用灰色；缺少当前期或同期有效报表时显示暂无，不以零值补造结果。
- 自定义卡片覆盖经营表与推广表全部可计算指标，整店自定义卡片可直接加入多选趋势；每个趋势系列独立缩放。

## 日期、上传与数据仓

- 修复月底相邻日期已上传却未进入本地日环比的问题，比较范围统一从当前筛选结束日期推导，并继续隔离店铺、周期和实体维度。
- 桌面端与网页端支持多文件批量上传、逐份识别与进度反馈、店铺/日期/周期校正、失败单独重试；中文 CSV 优先按 UTF-8 解码，再执行 GBK/GB18030 兼容判断。
- 团队上传默认使用当前团队的单一店铺，同时保留手工修改入口。
- 数据仓库按“店铺 > 统计日期 > 报表”归档，支持店铺、日期、单份报表三级选择与批量管理，最新日期优先。
- 销售扣除完整历史始终可见，只有命中当前店铺和日期范围的记录进入净 GSV、经营 ROI 与推广费率计算。

## 商品资料与经营结构

- 商品资料支持分页批量选择和批量修改店铺、品类、型号；更新使用 `replacesId` 保留追加式版本链，并拦截重复数据和过期提交。
- 团队网页版新增 `PATCH /api/teams/:teamId/product-catalog/bulk` 批量维护接口及权限、重复和旧版本测试。
- 新增共享类目贡献模块，桌面端与网页端统一展示销售占比、花费占比、类目推广费率和动态对比条。
- 净 GSV、推广费率、经营 ROI 与类目贡献继续使用共享计算核心，确保重新建团队、重新上传和切换日期后口径不漂移。

## 分发

- 桌面应用与团队网页版版本统一为 `1.0.37`，项目说明、中文使用手册、自部署说明和版本介绍同步更新。
- GitHub Actions 构建 Windows x64、macOS Intel 和 macOS Apple Silicon 安装包，并在三端测试通过后创建正式 Release。

# v1.0.36

## 整店经营结构

- 桌面端与团队网页版新增“类目销售贡献与推广效率”，按当前日期、店铺和报表口径统一计算。
- 每个类目同屏展示净 GSV、销售占比、推广花费、花费占比和类目推广费率，并明确标注计算公式。
- 占比分母使用当前筛选范围内全部有效类目，榜单按净 GSV 展示前 10；未满足同周期证据时费率显示 `--`。
- 品类 360 与商品排行补充 TOP 10 净 GSV / 推广花费对比和费率标签，柱状图与日、周、月、自定义日期同步联动。

## 筛选、展开与移动端

- 商品品类和型号筛选双向联动，自动移除当前品类下不存在的型号及当前型号下不存在的品类。
- 修复筛选下拉框被父容器裁切、桌面与手机端可用空间不足、打开后闪退等问题。
- 单品与品类推广详情使用独立抽屉承载，一次只打开一项，不再重建大表格、改变滚动位置或跳到其他型号。
- 团队网页版增加面向老板查看的手机布局，四个运营页面、经营卡片、筛选、图表和明细表均针对窄屏重排。
- 网页初始化失败不再白屏，显示失败原因和重试按钮，可在服务恢复后直接重新加载。

## 开源与分发

- 本地开发源码版同步团队网页版最新经营总览，并继续使用共享运营计算核心。
- 更新桌面端、团队网页版、中文 README、使用说明与自部署文档到 `v1.0.36`。
- GitHub Release 同时提供 Windows x64、macOS Intel 和 macOS Apple Silicon 安装包。

# v1.0.31

## 商品工作台重做

- 商品监控收敛为单一工作台：筛选、批量操作、商品列表、任务中心和新增商品在同一条工作流内完成。
- 商品列表改为高密度工作卡，固定展示商品、已验证最低价、账号与监控状态；外层直接提供核对、定时、飞书、抓取和删除。
- 点击商品进入预览，集中查看 SKU、所有已验证价格通道、计算公式、账号视角、监控价、定时计划、主图、素材和买家秀；预览不再重复外层操作。
- 单品计划改为两步：卡片“定时”启用或暂停商品，预览中设置单次/循环并保存计划，避免开关和时间设置混淆。
- 桌面端保持完整操作文字，窄屏自动切换为有提示的图标操作轨；移动端顶栏不再透出滚动内容。

## 抓取与价格核验

- 浏览器首次打开商品页时等待 SKU 选择索引和价格数据就绪后再采集，降低首轮空壳页面造成的部分 SKU 缺失。
- 价格采集继续严格使用授权浏览器取证、脱敏原子落盘、从本地文件读回后解析的链路；后端不直接请求淘宝或天猫商品、价格、优惠和评价接口。
- 商品卡片“核对”可直接逐 SKU 查看金额、当前证据和闭合计算公式；未取得明确证据的通道保持“未获取”，不会用标价、历史价或其他账号补造。
- 修复商品型号回退为“未识别型号”：本地解析现在复用商品页“型号/产品型号/货号”基础参数识别；已有商品会从已保存的脱敏本地证据自动补齐型号，不重新打开淘宝页面，也不改写任何价格或监控价。

## 说明与分发

- 软件内“使用说明书”和仓库中文说明同步更新到当前商品工作台路径与按钮含义。
- 文档中的商品工作台与使用说明截图重新生成并进行敏感信息马赛克处理。
- 安装包继续使用明确的构建白名单，排除本机数据库、账号浏览器目录、Cookie、抓取证据、运行日志和生成素材。

## 运营助手与数据导入

- 运营助手支持 QwenPaw 本机运行、模型配置同步、可审计的本地工具调用和持续保留的对话界面。
- 运营报表上传补全 XLS、XLSX、CSV、JSON 与图片识别，预览会明确显示字段和行数，便于核对导入是否完整。
- 账号状态区分“账号掉线”和“部分 SKU 价格证据待补齐”；后者不会错误引导用户重新扫码。
