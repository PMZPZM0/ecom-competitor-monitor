# 经营罗盘 v1.0.38

本版把品类 360 和商品排行的自定义数据与环比收进经营矩阵本身。老板或运营不需要在上方大卡片和明细表之间来回核对，每一行就能同时看到当前值、同期变化、排序结果和推广计划。

## 矩阵行级环比

- 品类 360 与商品排行移除重复的大指标卡，环比直接进入每条经营矩阵记录。
- 支付金额、成功退款、净 GSV、推广花费、推广成交、ROI、推广费率以及自定义字段均可显示当前周期环比。
- 环比严格按当前店铺、当前品类或商品、当前报表周期匹配同期数据，不使用其他店铺、其他实体或不完整报表补位。
- 品类和商品分别提供独立开关并持久化；上涨红色、下降绿色、无同期证据显示灰色 `--`。

## 最多 8 个自定义数据列

- 品类和商品矩阵均可从标准化经营表、推广表字段中追加最多 8 个数据列。
- 自定义列可点击表头排序，也可在设置中拖动换位或使用上移、下移按钮精确调整。
- 字段选择、字段顺序和环比开关按用户及团队分别保存，刷新后仍保留；达到 8 项上限时会明确禁用未选字段。

## 性能与手机布局

- 筛选结果、汇总结果、同期实体索引和矩阵行渲染增加缓存，减少切换排序、环比及自定义字段时的重复计算。
- 手机端把固定字段和自定义字段重排为紧凑卡片，矩阵滚动保持在组件内部，避免整页横向溢出。
- 桌面开发版与团队网页版同步采用相同计算行为、字段上限、排序逻辑和视觉反馈。

## 开源团队网页版

- `cloud-data-hub` 完整源码随仓库发布，可独立部署账号登录、团队/店铺权限、邀请码、设备授权、报表上传、商品资料和经营看板。
- 提供 Docker Compose、Node.js + systemd 与反向代理部署说明；升级网页服务不会删除已有数据库、上传文件或环境配置。
- 网页仅保存团队主动上传的经营报表与治理数据，不保存本机淘宝登录、Cookie、飞书凭证、模型 Key 或价格证据。

## 价格数据边界

本版没有改动淘宝/天猫价格采集链路。价格仍只从用户授权浏览器中观察，敏感内容脱敏后原子写入本地文件，再从该文件读回并解析。后端不会直接请求淘宝或天猫商品、价格、优惠或评价接口；证据不能精确闭合到分时保持不可用。
