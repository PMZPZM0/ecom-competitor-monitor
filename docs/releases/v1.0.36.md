# 经营罗盘 v1.0.36

本版重点把桌面端与开源团队网页版的经营看板统一到同一套老板视角：关键金额、占比、费率和公式在一屏内说清楚，同时解决大表格展开卡顿、筛选裁切与手机查看不便。

## 整店总览

- 新增“类目销售贡献与推广效率”，按净 GSV 排名前 10 展示类目结构。
- 每个类目同屏显示净 GSV、销售占比、推广花费、花费占比和类目推广费率。
- 页面直接标明：销售占比 = 类目净 GSV ÷ 有效类目净 GSV 合计；花费占比 = 类目推广花费 ÷ 有效类目推广花费合计；类目推广费率 = 类目推广花费 ÷ 类目净 GSV。
- 合计与排名跟随当前日期、店铺和报表周期筛选；缺少同周期有效证据时费率保持 `--`，不会补造数字。
- 桌面开发源码版与团队网页版复用同一个运营计算核心，避免重新建团队或重新上传后出现公式漂移。

## 品类 360 与商品排行

- 两个页面均增加 TOP 10 净 GSV / 推广花费对比，并在每项旁标注推广费率。
- 图表使用当前工作区结果，自动跟随今天、昨天、上周、本月、上月、自定义日期、店铺和报表口径。
- 商品品类与型号筛选双向联动：选择品类后只显示可用型号，选择型号后同步收窄品类，并清除已失效选项。
- 修复筛选下拉框被裁切、打开后消失，以及窄屏下内容显示不完整的问题。
- 推广计划详情改为独立抽屉，一次只打开一项。展开不会重建整张表、改变滚动位置或跳到其他型号，品类和单品均使用相同的稳定机制。

## 手机经营视图

- 团队网页版新增专门的移动端经营布局，四个运营入口、日期与店铺筛选、核心指标、类目结构和经营矩阵按手机宽度重排。
- 核心指标使用两列紧凑卡片；经营矩阵在手机上转为带字段标签的数据卡，不再依赖横向大表格。
- 推广计划详情在手机底部抽屉显示，保留净 GSV、花费、费率、推广类型和计划明细。

## 网页稳定性与开源部署

- 网页首次加载失败不再停留空白页，新增错误说明和重试入口。
- 团队网页版源码、权限系统、报表上传、商品资料、设备授权、Docker Compose、systemd 和 Caddy 部署示例继续完整开源。
- 桌面端只读同步获授权团队报表；淘宝登录、Cookie、价格证据、飞书凭证、模型 Key 和 QwenPaw 本地数据不会上传。

## 验证

- 桌面端执行自动化测试、代码检查、生产构建与 Windows 安装包构建。
- 团队网页版执行完整接口与界面契约测试。
- GitHub Actions 分别构建 Windows x64、macOS Intel 和 macOS Apple Silicon 安装包，并验证 macOS 包完整性。

- Windows：`JingYingLuoPan-1.0.36-win-x64.exe`
- Intel Mac：`JingYingLuoPan-1.0.36-mac-x64.dmg`
- Apple Silicon Mac：`JingYingLuoPan-1.0.36-mac-arm64.dmg`
