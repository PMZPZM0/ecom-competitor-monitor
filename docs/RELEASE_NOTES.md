# v1.0.36

## 整店经营结构

- 桌面端与团队网页版新增“类目销售贡献与推广效率”，按当前日期、店铺和报表口径统一计算。
- 每个类目同屏展示净 GSV、销售占比、推广花费、花费占比和类目推广费率，并明确标注计算公式。
- 占比分母使用当前筛选范围内全部有效类目，榜单按净 GSV 展示前 10；未满足同周期证据时费率显示 `--`。
- 品类 360 与商品排行补充 TOP 10 净 GSV / 推广花费对比和费率标签，柱状图与日、周、月、自定义日期同步联动。

## 筛选、展开与移动端

- 商品品类和型号筛选双向联动，自动移除当前品类下不存在的型号及当前型号下不存在的品类。
- 修复筛选下拉框被父容器裁切、桌面与手机端可用空间不足、打开后闪退等问题。
- 单品与品类推广详情使用独立抽屉承载，一次只打开一项，不再重建大表格、改变滚动位置或跳到其他型号。
- 团队网页版增加面向老板查看的手机布局，四个运营页面、经营卡片、筛选、图表和明细表均针对窄屏重排。
- 网页初始化失败不再白屏，显示失败原因和重试按钮，可在服务恢复后直接重新加载。

## 开源与分发

- 本地开发源码版同步团队网页版最新经营总览，并继续使用共享运营计算核心。
- 更新桌面端、团队网页版、中文 README、使用说明与自部署文档到 `v1.0.36`。
- GitHub Release 同时提供 Windows x64、macOS Intel 和 macOS Apple Silicon 安装包。

# v1.0.31

## 商品工作台重做

- 商品监控收敛为单一工作台：筛选、批量操作、商品列表、任务中心和新增商品在同一条工作流内完成。
- 商品列表改为高密度工作卡，固定展示商品、已验证最低价、账号与监控状态；外层直接提供核对、定时、飞书、抓取和删除。
- 点击商品进入预览，集中查看 SKU、所有已验证价格通道、计算公式、账号视角、监控价、定时计划、主图、素材和买家秀；预览不再重复外层操作。
- 单品计划改为两步：卡片“定时”启用或暂停商品，预览中设置单次/循环并保存计划，避免开关和时间设置混淆。
- 桌面端保持完整操作文字，窄屏自动切换为有提示的图标操作轨；移动端顶栏不再透出滚动内容。

## 抓取与价格核验

- 浏览器首次打开商品页时等待 SKU 选择索引和价格数据就绪后再采集，降低首轮空壳页面造成的部分 SKU 缺失。
- 价格采集继续严格使用授权浏览器取证、脱敏原子落盘、从本地文件读回后解析的链路；后端不直接请求淘宝或天猫商品、价格、优惠和评价接口。
- 商品卡片“核对”可直接逐 SKU 查看金额、当前证据和闭合计算公式；未取得明确证据的通道保持“未获取”，不会用标价、历史价或其他账号补造。
- 修复商品型号回退为“未识别型号”：本地解析现在复用商品页“型号/产品型号/货号”基础参数识别；已有商品会从已保存的脱敏本地证据自动补齐型号，不重新打开淘宝页面，也不改写任何价格或监控价。

## 说明与分发

- 软件内“使用说明书”和仓库中文说明同步更新到当前商品工作台路径与按钮含义。
- 文档中的商品工作台与使用说明截图重新生成并进行敏感信息马赛克处理。
- 安装包继续使用明确的构建白名单，排除本机数据库、账号浏览器目录、Cookie、抓取证据、运行日志和生成素材。

## 运营助手与数据导入

- 运营助手支持 QwenPaw 本机运行、模型配置同步、可审计的本地工具调用和持续保留的对话界面。
- 运营报表上传补全 XLS、XLSX、CSV、JSON 与图片识别，预览会明确显示字段和行数，便于核对导入是否完整。
- 账号状态区分“账号掉线”和“部分 SKU 价格证据待补齐”；后者不会错误引导用户重新扫码。
